# Sound credits

Every file here is cut from CC0 (public domain) recordings by `tools/make_sounds.py` (ADR 0044). No attribution is required; this list traces each sound to its source.

## Sources

- `kenney/`: Kenney CC0 packs: https://kenney.nl/assets/impact-sounds, rpg-audio, interface-sounds, ui-audio (one folder per zip)
- `bigsoundbank/<id>.ogg`: BigSoundBank, all CC0: https://bigsoundbank.com/UPLOAD/ogg/<id>.ogg (the sound's page: https://bigsoundbank.com/search?q=<id>)
- `oga-holizna-title-screens/`: HoliznaCC0, Title Screens (Beginnings Collection), CC0: https://opengameart.org/content/title-screens-beginnings-collection
- `oga-yoiyami/`: Yoiyami, CC0 on OpenGameArt: sunset-plains, yoiyami-core-theme, the-budding-of-consciousness, first-light-particles (node/182244)
