# Quest-worthy content (for the recipe-browser / progression book session)

Items from the content lane (ADR 0112, 0121) that deserve a quest or a book entry. The recipe-browser
session wires them; this list only names them, with the age they belong to and why.

| Item(s) | Age | Why a quest |
|---|---|---|
| `birch_planks`, `spruce_planks`, `acacia_planks`, `jungle_planks` | Flint | each wood its own planks: "build with two woods" |
| any `*_sapling` placed | Flint | replant a forest: plant a sapling and watch it grow |
| `porridge` | Flint / Bronze | the first warming meal (cooking pot + grain) |
| `fish_soup`, `mushroom_soup`, `berry_compote` | Flint / Bronze | meals with buffs: eat one of each |
| `bronze_helmet`, `bronze_chestplate`, `bronze_boots` | Bronze | first full metal armour set |
| `bronze_spear` | Bronze | first metal weapon |
| `iron_chestplate`, `iron_spear` | Iron | iron gear |
| `steel_axe`, `steel_saw`, `steel_hammer` | Steel | the steel tool set after the steel pickaxe |
| `steel_helmet`, `steel_chestplate`, `steel_boots` | Steel | full steel armour |
