# Speed debt

What features cost that has not been won back yet (CLAUDE.md principle 14, ADR 0096). One row per feature,
written when it is merged, from one measurement on a quiet PC (`play` build, quick runs, the median of three).
An optimisation batch works down this list, most expensive first, CPU before GPU, and strikes rows out.

Budget (ADR 0004): frame p99 <= 8.3 ms, no frame > 16.7 ms. Main on 2026-11-13: fly GPU p50 2.9 ms,
frame p99 6.3 ms, frame-thread work 0.58 ms; sim work 0.59 ms. After ADR 0111 (2026-11-14, interleaved A/B):
fly p99 5.25 ms (max 8.2), sim 6.22, orbit 7.61 (max 10.4): the 1080p budget holds; the TLAS build's spike
(65,536 slots walked a build) is gone. After ADR 0120 (2026-11-14, release build, interleaved A/B): every 1080p run inside the budget
(fly p99 5.21 ms, sim 5.97, orbit 7.69, edit 7.73); what is over is the GPU at 2560 x 1440 (forest 16.7 ms) and,
under it, the walk at detail 8 in flight (4.1 ms a frame).

    and `clutter::column` builds a chunk's whole edit list (`edits_for`) to test one column: both on the frame
    thread.
